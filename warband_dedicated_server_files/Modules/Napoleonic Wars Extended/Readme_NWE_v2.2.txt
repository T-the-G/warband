# Non-exhaustive list of features:

### Main new features of Napoleonic Wars Extended (NWE):

Two factions per team
New units in every faction
New factions: the Ottoman Empire and the Kingdom of Italy
Flag spawning game mode recoded entirely, with scripts for FIC, FOL, OA, Rambo, Crouching and All Charge
New game mode: Flag Spawning Commander Battle, with new orders to move bots like players. Bots can even fire cannons!


### New gameplay elements:
New class: horse artillery
You can attack with flags and pistols
Artillery trains can spawn with mortars
Health healed by surgeons is modifiable
Surgeons can spawn with a musket
Sappers can spawn with a horse
New units with camels


### New chats:
Sending direct messages to one player in the game (Whisper)
Officer chat (by pressing Ctrl + I)
Local chat (by pressing O)
Admin chat without announcement (by pressing Ctrl + U)


### For players:
Display usernames of close players (by pressing Left Ctrl)
Display usernames of players of the same unit (by pressing Left Alt)
Interact with players by clicking on their names (by pressing Ctrl + C or Alt + C)
"Never mute" option to keep seeing the messages of specific players even when muting everyone (same menu as Mute/Unmute)
In Flag spawning mode, a player status displays if the player is respecting the FIC/FOL/Rambo rules
In Flag spawning mode, a flag bearer status displays if the player can make teammates respawn


### For admins:
"Units Overview" menu with the list of playable units and their players
Redesign of the admin panel with lots of new parameters
Admin tools to perform admin actions easily on a single player or several players at the same time
Muting a player server side
Copy the username of a player and paste it in a chat with Ctrl + V (except for global chat and team chat)
Assign regiments to units in the "Regiment Assignment" menu
Change the Ban hammer effect
All Charge mode cancelling firing damages
Ceremony mode cancelling all damages


### Appearance:
You can show/hide the plume of your own shako (in the "Mod Options" menu)
New accessories, including "double" accessories (eye patch + beard for example)


The base of the game is still the same, with no definitive modification/removal, every new feature can be turned off in the admin panel.
